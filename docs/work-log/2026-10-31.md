# Work summary: October 31, 2026

Implemented and ran claim-level faithfulness evaluation for the Medical RAG
project. Claude Sonnet 5.5 judged 30 Llama 3.1 answers against their exact supplied
context. Mean per-answer faithfulness was **89.9%**: 315 of 344 extracted claims
were labeled supported, with no remaining judge failures.

## Changes

- Added optional pipeline tracing for full answers, ordered context chunks,
  retrieval scores, prompts, and answer/abstention status.
- Extended benchmark capture with question selection, checkpointing, and reuse
  of matching pilot answers. Corrected fallback detection and distinguished
  keyword matching from answer accuracy in the displayed metrics.
- Added a separate faithfulness evaluator with Anthropic and Gemini providers,
  atomic claim extraction, structured support verdicts, exact evidence checks,
  bounded retries, request timings, token usage, and resumable runs.
- Added safe reuse of judgments only when model settings, prompts, questions,
  full answers, and context match. Invalid Unicode quote escaping is decoded
  only when it produces an exact source match, with the raw quote preserved.
- Documented the workflow, six-answer pilot review, full results, limitations,
  and updated the README to avoid equating citation or keyword checks with
  correctness.

## Execution and validation

The Ollama Qwen3.5 download failed because the installed Ollama version was too
old; no new model was installed. Gemini judging was attempted and then stopped
at the user's request after one completed answer. Evaluation switched to the
user's funded Anthropic account. Six pilot answers and verdicts were reused,
and the remaining 24 were generated and judged. The user reviewed the pilot
and chose to retain the original judge labels and caveats.

All seven offline tests pass. Final score arithmetic, 30 unique answer IDs,
evidence quotes, and unchanged pilot labels were verified. Estimated Anthropic
token cost was $0.80 including pilot calls and retries; this is not a billing
statement. Known ambiguous source text and inconsistent judge reasons remain
documented. This score estimates context support, not medical accuracy.

Credentials in `.env`, raw evaluation files under `data/`, and unrelated local
`.claude/` worktrees are excluded from this commit.
